# Security Policy

## Reporting a vulnerability

**Please do not open a public issue for security vulnerabilities.**

Email **security@studio51.solutions** with:

- a description of the issue and its impact,
- steps to reproduce (proof-of-concept if possible),
- any suggested remediation.

We aim to acknowledge reports within **3 business days** and to provide a
remediation timeline after triage. We'll keep you updated and credit you in the
release notes once a fix ships, unless you prefer to remain anonymous.

## Supported versions

Unless stated otherwise in the [README](README.md), only the latest released
version of Observatory receives security fixes.

## Scope

This policy covers the code in this repository. Vulnerabilities in third-party
dependencies should be reported upstream, though we appreciate a heads-up at
security@studio51.solutions so we can pin or patch.
